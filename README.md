This is a project inspired by [Starbie](https://github.com/SharKingStudios/Starbie/tree/main). It's called Planetie since its sort of a rip off and more planet based rather than a star. It was made it KiCad for hackclub's Half Life program
What it does is it displays the main sprite on a OLED screen doing things depending on input from the user or the environment using buttons, and motion and environment sensors.

To assemble it, get the circuit board printed, get the parts from the BOM, and solder it accordingly. To get the firmware on Xiao, plug it into your computer, hold the reset button, and drag the firmware file into the folder for the Xiao on your computer.

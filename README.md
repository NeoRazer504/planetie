This is a project inspired by [Starbie](https://github.com/SharKingStudios/Starbie/tree/main). It's called Planetie since its sort of a rip off and more planet based rather than a star. 
What it does is it displays the main sprite on a OLED screen doing things depending on input from the user or the environment using buttons, and motion and environment sensors.
